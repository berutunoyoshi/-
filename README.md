# RCCM 問題3 暗記ノート

RCCM試験 問題3（記述式）の6つの公表問題について、見本答案を覚えるためのWebアプリです。
ブラウザだけで動き、サーバーやビルドは不要です。

## できること

- **紙芝居**：答案の流れを、イラストと物語でつかみます（6問それぞれ9〜10場面）。各場面に、答案のどの項目にあたるかと対応する指定用語を表示します。スワイプ・ボタン・左右キーでめくれ、「▶ 自動で上演」では語りを読み上げながら自動でめくります。
- **読む**：見本答案を ①→(1)→・ の構成のまま通読します。指定用語は青字で表示します。
  「▶ 読み上げ」で端末の音声合成（Web Speech API）が1行ずつ読み上げ、読んでいる行に色が付きます。速さは4段階で選べ、読み上げ中に行をタップするとその行から読み直します。
- **骨子**：各項目の書き出しだけを表示します。続きを思い出してからタップして確認します。
- **穴埋め**：指定用語と数値を隠します。タップでめくり、めくった数を表示します。
- **書く**：何も見ずに答案を入力します。字数（1200〜1600字の範囲）と、「 」で囲んだ指定用語の数をその場で数えます。用語ボタンで「用語」を挿入でき、見本と並べて比べられます。
- 「覚えたら押す」で設問ごとの習得状況を記録します。

下書きと習得状況は、使っている端末のブラウザ（localStorage）に保存されます。別の端末とは共有されません。

## ファイル構成

```
index.html   画面
style.css    デザイン（ライト／ダークモード対応）
app.js       動作
data.js      設問と見本答案のデータ
reading.js   読み上げの読み替え辞書（例：群マネ→ぐんまね）
story-data.js 紙芝居の語り
story.js     紙芝居のイラスト（SVG）
tools/generate_voice.py  ずんだもん音声の作成スクリプト
audio/       作成した音声（スクリプト実行後にできる）
```

答案を直したいときは `data.js` の `answer` を編集してください。1行が1項目で、行頭が「①②」なら大見出し、「(1)」なら小見出し、「・」なら箇条、それ以外は地の文として表示されます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`rccm3-memo`）。
2. このフォルダの中身（各ファイルと tools フォルダ、音声を作った場合は audio フォルダ） をリポジトリの直下にアップロードします（「Add file」→「Upload files」）。
3. リポジトリの「Settings」→「Pages」を開き、「Source」で「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/rccm3-memo/` で開けるようになります。

スマートフォンのホーム画面に追加すると、アプリのように起動できます。

## ずんだもんの声で読み上げる（VOICEVOX）

audio フォルダがないときは端末の音声合成で読み上げ、あるときはずんだもんの音声を再生します。音声は一度だけ作成してリポジトリに置きます。作り方は2通りあります。

### スマホだけで作る（GitHub Actions）

パソコンが無くても、GitHub のサーバー上で VOICEVOX を動かして音声を作れます。

1. リポジトリに `.github/workflows/voice.yml` と `tools/generate_voice.py` があることを確認します。
2. 「Actions」タブを開きます。初回は「I understand my workflows, go ahead and enable them」を押して有効にします。
3. 左の一覧から「ずんだもん音声を作成」を選び、「Run workflow」を押します（速さや作る設問も選べます）。
4. 30分前後で完了し、`audio` フォルダが自動でリポジトリに追加されます。数分後に公開ページへ反映されます。

失敗して「Permission denied」などと出る場合は、「Settings」→「Actions」→「General」→「Workflow permissions」を「Read and write permissions」にして再実行してください。
Private リポジトリでは GitHub Actions の無料枠（月2,000分）を使います。Public リポジトリは無料です。

### パソコンで作る

1. パソコンに [VOICEVOX](https://voicevox.hiroshiba.jp/) をインストールして起動します（起動したままにします）。
2. Python 3 を用意します。mp3 で保存したい場合は ffmpeg も入れます（無い場合は wav で保存され、容量が大きくなります）。
3. このリポジトリのフォルダで次を実行します。

   ```
   python tools/generate_voice.py
   ```

   全部で196本の音声を作ります。パソコンの性能によりますが、十数分ほどかかります。mp3 で合計 20MB 前後の見込みです。
4. できた `audio` フォルダを GitHub にアップロードします。

主なオプション：`--speed 1.1`（話す速さ）、`--only 3`（設問3だけ作り直す）、`--list-speakers`（話者IDの一覧。ずんだもんのノーマルは3。ほかの声にするときは `--speaker 番号`）。

答案や読み替え辞書を直したら、もう一度スクリプトを実行してください。変わった文だけが作り直され、使われなくなった音声は自動で削除されます。アプリは文章が一致する音声だけを再生し、一致しない行は端末の音声合成で読むので、作り直す前でも動作します。

### 読み方を直したいとき

`reading.js` に `["書いてある文字", "読ませたい読み"]` を追加します。ブラウザの読み上げと VOICEVOX の両方に効きます。

### クレジットと利用規約

ずんだもんの音声を使う場合は「VOICEVOX:ずんだもん」のクレジット表記が必要です。アプリでは画面下部と読み上げ欄に自動で表示します。公開前に、VOICEVOX とずんだもんの利用規約の最新版を確認してください。

## 読み上げについて

- 端末に入っている日本語の音声を使います。iPhone・Android・Windows・Mac の主要ブラウザで動作します。
- 音声が出ない場合は、端末の設定で日本語の読み上げ音声が入っているか、消音モードになっていないかを確認してください。
- 「①」「(1)」は「設問1」「項目1」と読み替えています。用語の読み方は reading.js で調整できます。

## 注意

- 見本答案は国土交通白書2026と受験対策サイトの骨子例をもとに作成した学習用の例です。
- リポジトリを公開（Public）にすると、答案の内容も誰でも閲覧できます。非公開にしたい場合は Private リポジトリにしてください（無料プランでは Private リポジトリの GitHub Pages は使えません）。
