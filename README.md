# RCCM 問題3 暗記ノート

RCCM試験 問題3（記述式）の6つの公表問題について、見本答案を覚えるためのWebアプリです。
ブラウザだけで動き、サーバーやビルドは不要です。

## できること

- **紙芝居**：答案の流れを、イラストと物語でつかみます（現在は(1)インフラ老朽化のみ・試作版）。各場面に、答案のどの項目にあたるかと対応する指定用語を表示します。スワイプ・ボタン・左右キーでめくれ、「▶ 自動で上演」では語りを読み上げながら自動でめくります。
- **読む**：見本答案を ①→(1)→・ の構成のまま通読します。指定用語は青字で表示します。
  「▶ 読み上げ」で端末の音声合成（Web Speech API）が1行ずつ読み上げ、読んでいる行に色が付きます。速さは4段階で選べ、読み上げ中に行をタップするとその行から読み直します。
- **骨子**：各項目の書き出しだけを表示します。続きを思い出してからタップして確認します。
- **穴埋め**：指定用語と数値を隠します。タップでめくり、めくった数を表示します。
- **書く**：何も見ずに答案を入力します。字数（1200〜1600字の範囲）と、「 」で囲んだ指定用語の数をその場で数えます。用語ボタンで「用語」を挿入でき、見本と並べて比べられます。
- 「覚えたら押す」で設問ごとの習得状況を記録します。

下書きと習得状況は、使っている端末のブラウザ（localStorage）に保存されます。別の端末とは共有されません。

## ファイル構成

```
index.html   画面
style.css    デザイン（ライト／ダークモード対応）
app.js       動作
data.js      設問と見本答案のデータ
story.js     紙芝居の場面とイラスト（SVG）
```

答案を直したいときは `data.js` の `answer` を編集してください。1行が1項目で、行頭が「①②」なら大見出し、「(1)」なら小見出し、「・」なら箇条、それ以外は地の文として表示されます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`rccm3-memo`）。
2. このフォルダの5つのファイルと README.md をリポジトリの直下にアップロードします（「Add file」→「Upload files」）。
3. リポジトリの「Settings」→「Pages」を開き、「Source」で「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/rccm3-memo/` で開けるようになります。

スマートフォンのホーム画面に追加すると、アプリのように起動できます。

## 読み上げについて

- 端末に入っている日本語の音声を使います。iPhone・Android・Windows・Mac の主要ブラウザで動作します。
- 音声が出ない場合は、端末の設定で日本語の読み上げ音声が入っているか、消音モードになっていないかを確認してください。
- 「①」「(1)」は「設問1」「項目1」、「BIM/CIM」は「ビム・シム」と読み替えています。読み方を変えたい場合は app.js の `speakable` 関数を編集してください。

## 注意

- 見本答案は国土交通白書2026と受験対策サイトの骨子例をもとに作成した学習用の例です。
- リポジトリを公開（Public）にすると、答案の内容も誰でも閲覧できます。非公開にしたい場合は Private リポジトリにしてください（無料プランでは Private リポジトリの GitHub Pages は使えません）。
